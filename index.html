문제 정의

글로벌 펫 시장은 빠르게 성장하지만, 신원·의료·검역·평판 데이터는 여전히 분절되어 있고 조작과 분실에 취약합니다.

검역 및 의료기록의 비신뢰성

종이 서류와 중앙화 DB 중심 구조는 분실, 위조, 국가 간 제출 지연을 반복적으로 유발합니다.

혈통 및 브리딩 투명성 부족

출생 정보와 혈통이 투명하지 않아 불법 브리딩, 펫숍 사기, 건강 정보 위조가 지속됩니다.

평판 조작과 서비스 안전성

리뷰 조작을 막을 온체인 검증 수단이 부족해 펫시터·도그워커·브리더의 신뢰를 확인하기 어렵습니다.

Pet ID SBT

반려동물별 고유의 비양도성 신원 토큰을 발급해 생애 전 주기 데이터를 연결합니다.

Microchip Hash Lineage Root Lifetime Record

Proof-of-Service Oracle

실제 거래, 진료, 서명된 의료 NFT를 기반으로만 평판을 남기게 하여 리뷰 조작을 억제합니다.

Verified Review Escrow Slashing

Pet M2E Loop

산책·활동 데이터를 보상화하고, 건강 데이터셋으로 전환해 장기적으로 Pet ID에 누적합니다.

GPS Wearable Health Data

기술 아키텍처

수의사는 복잡한 지갑/가스비를 의식하지 않고 기존 EMR 화면에서 자연스럽게 온체인 인증을 발행합니다.

01
Vet-DID 인증으로 수의사 신원과 병원 자격을 검증합니다.
02
EMR 저장 시 공적 데이터만 자동 추출해 API 브릿지로 전송합니다.
03
ERC-4337 계정 추상화로 가스비를 대납하고 인증 NFT를 즉시 민팅합니다.
04
발급된 기록은 Pet ID SBT에 귀속되어 검역·이동·이력 관리에 활용됩니다.

FAQ

왜 SBT인가요?

반려동물의 신원과 의료 이력은 팔 수 있는 자산이 아니라, 특정 개체에 고정된 신뢰 레이어이기 때문입니다.

왜 NFT가 필요한가요?

진료, 백신, 혈통 증명처럼 시점과 발급 주체가 중요한 문서를 검증 가능하게 만들기 위해서입니다.

EMR 연동의 장점은?

수의사가 새로운 툴을 배우지 않아도 기존 업무 흐름 안에서 온체인 증명이 자동화되기 때문입니다.
